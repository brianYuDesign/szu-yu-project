# Day 5 — 面試演練（3.5h）

**產出**：90 秒自我介紹、五題預演、追問防守清單

---

## 任務 1：90 秒自我介紹（45 分鐘）

結構固定：**現在做什麼（30s）→ 最能代表我的一件事（40s）→ 想找什麼（20s）**

草稿（依你的實際情況改）：

> 我是 Brian，8 年軟體開發經驗，目前是 AI 工程師。過去一年我獨立開發一款交友配對與興趣社群 App，從需求規劃、AI 功能設計、後端服務一路做到 iOS 上架。
>
> 最能代表我的是把 Claude 做成產品裡真的在用的功能 —— 配對建議、聊天教練、破冰話題生成，同時搭一套內容安全管線（Rekognition 圖片同步、影片非同步審核、真人驗證）。後端是 NestJS，180 多支 API、1000 多項自動化測試。最近我補了 AI 品質的部分：建了標註 eval set 和評分標準，prompt 改動都會跑迴歸驗證，並追蹤生成內容的採納率跟呼叫成本。
>
> 我在找的是能把一條 AI 產品線持續做深的位置。先前帶過 11 人團隊、建過 review 與 release 流程，但接下來我想先把技術做深，走獨立 IC。

**三個檢查點**：
- 前 10 個字有沒有出現 AI？
- 有沒有講到硬數字？
- 有沒有明確說出想要什麼？（很多人只講過去，不講方向）

**不要出現的字**：救火、什麼都做、都有碰、比較雜。

---

## 任務 2：五題預演（90 分鐘）

每題寫下 100–150 字的答案主幹，然後**唸出來**。寫得出來不代表講得出來。

### Q1「講一個你把 AI 接進產品的例子」
→ 直接用 Day 2 案例 A。重點放在**取捨**：為什麼用 LLM 不用規則？哪些請求你決定不打模型？

### Q2「你怎麼確保模型輸出的品質？」★ 這題決定你是不是「做深」
→ 用 Day 3 的 eval set + 評分標準 + prompt 迴歸驗證回答。
講清楚：標了幾筆、幾個維度、改動後分數變化。**具體數字比方法論名詞有用。**

### Q3「模型出錯或逾時的時候會怎樣？」
→ 降級策略。有沒有 fallback 文案？有沒有重試？使用者會不會看到錯誤？
若目前沒有做完整，就誠實說「目前做到 X，我知道下一步該做 Y」——比硬掰安全，而且顯示你有在想。

### Q4「你怎麼影響團隊？」／「你想帶人嗎？」
→ 云桐的 11 人團隊、12 款產品、design review / code review / release checklist（Day 2 準備的第三份素材）。

履歷保留了管理經驗，所以**一定會被追問「你到底想不想帶人」**。準備一個兩面都不關門的答案：

> 「我帶過 11 人團隊，也建過 review 跟 release 的流程，那段經驗我覺得很有價值。接下來我想把重心放在技術做深 —— 特別是 AI 這塊。如果角色需要帶一兩個人或主導技術方向，我做得來也願意；但我不想把時間全部放在管理上。」

三個作用：承認經驗、講清楚偏好、不把 Tech Lead 類職缺關掉。

### Q5「為什麼想離開現在的工作？」
→ **不要講前公司壞話，也不要講救火。**
往前講不往後講：「我想找一個能把一條 AI 產品線持續做深的環境，包含評估體系跟指標治理這些現在只做到基礎的部分。」

---

## 任務 3：追問防守清單（45 分鐘）

面試官在 Q1、Q2 之後最常追這幾刀。每一刀先想好答案：

| 追問 | 你要準備的 |
|------|-----------|
| 「一天呼叫幾次？月成本多少？」 | 實際數字，或至少量級（每日千次 / 月費用區間） |
| 「延遲多少？使用者會等嗎？」 | P95 延遲，以及有沒有做串流或非同步 |
| 「怎麼防 prompt injection？」 | 輸入清洗、輸出約束、敏感詞攔截這層怎麼接 |
| 「為什麼選 Claude 不選其他？」 | 至少講出一個具體理由（成本、中文品質、context 長度、結構化輸出） |
| 「eval 的 judge 準嗎？」 | 人工標註與自動評分的一致率，或直接說「目前以人工為準」 |
| 「1,066 個測試是怎麼來的？覆蓋率多少？」 | 測試分層（單元／整合／E2E）比例，別只講總數 |
| 「你一個人做，怎麼確保架構品質？」 | code review 缺席時的替代機制（測試、型別、design doc） |

**沒有答案的題目就寫「目前沒做，原因是 ___，若要做我會先 ___」**。這比含糊帶過強得多。

---

## 任務 4：模擬一次（30 分鐘）

找一個人（工程師朋友最好），請他照 Q1–Q5 問一輪，中間隨機插入追問清單裡的問題。全程錄音。

聽回放時只檢查三件事：
1. 有沒有講到「我怎麼知道這是好的」？（品質意識）
2. 有沒有出現「大概」「應該」「感覺」？（不確定的字眼）
3. 90 秒自介有沒有超過 2 分鐘？

沒有人可以找的話，自己錄一遍照樣有效——回放時的尷尬會告訴你哪裡沒想清楚。

---

## Day 5 驗收

- [ ] 90 秒自介不看稿講得完
- [ ] Q2 能講出具體數字（幾筆標註、幾個維度、分數變化）
- [ ] 追問清單七題都有答案，包含「目前沒做」的誠實版本
- [ ] 錄音聽過一次，且至少修正了一個問題

2. 每次面試後 24 小時內記錄：被問了什麼、哪題答不好、對方在乎什麼

4. **Day 3 的 eval 工作要持續做** —— 這是唯一會隨時間長大的資產，其他都是包裝
